# Roadmap

This is a direction for discussion, not a delivery commitment. Shipped behavior is described in the README and changelog.

## Near term

- Improve onboarding and add English UI/documentation progressively.
- Expand keyboard, screen-reader, high-contrast and reduced-motion coverage.
- Add installation examples for more NAS/proxy setups and tested backup retention options.
- Improve table density, saved views and classification review using real user feedback.

## Explore with the community

- Explicit graph relationships with provenance, evidence and useful navigation across versions.
- Agent integrations/MCP that retrieve permission-scoped artifact context, without silently importing transcripts.
- Personal writing/component preferences learned from approved feedback, with inspection, reset and export.
- Portable evaluation tasks that test component selection, evidence quality and author voice across agents.
- Better handoff from comment to change proposal, including which session/device created each revision.

A stronger graph should explain why two documents are connected. A learning system should show what it retained and let its owner change or remove it. Neither should turn private comments into shared training data by default.

Propose a concrete use case in an issue or discussion. Screenshots, reproducible examples and before/after expectations help prioritize more than feature counts.
